1. What is a Class?
class is a blueprint for creating objects.

2. What is an Object?
An object is an instance of a class.

3. Why OOP?
OOP helps us organize code and make it easier to reuse and maintain.

4. Three advantages of OOP:
- Code Reusability
- Maintainability
- Data Security

5. How does OOP help us organize and reuse code?
OOP organizes data and methods into classes. We can reuse code through objects and inheritance.

6. Access Modifiers
- Public: Accessible from anywhere allowed by the program. Example: a student's name.
- Private: Accessible only inside the same class. Example: a bank account balance.
- Protected: Accessible inside the class and its derived classes. Example: a person's name used by a derived class.
- Internal: Accessible within the same assembly. Example: a helper method used inside the same project.
